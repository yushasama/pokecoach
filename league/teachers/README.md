# Reference opponent notebooks (not included)

Training and league evaluation use four rule-based sample agents from the
Kaggle Pokémon TCG AI Battle competition as frozen opponents. Their license is
not stated where we downloaded them, so they are not in this repository (see
`CREDITS.md`). PokéCoach itself does not need them.

Download these Kaggle notebooks and save them here under these names:

| Kaggle notebook | Save as |
| --- | --- |
| a-sample-rule-based-agent-mega-abomasnow-ex-deck | `teacher_abomasnow.ipynb` |
| a-sample-rule-based-agent-iono-s-deck | `teacher_iono.ipynb` |
| a-sample-rule-based-agent-dragapult-ex-deck | `teacher_dragapult.ipynb` |
| a-sample-rule-based-agent-mega-lucario-ex-deck | `teacher_lucario.ipynb` |

`manifest.json` records the SHA-256 of the versions we used.
